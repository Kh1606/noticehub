 ICONS NEEDED — 10 organizations need a manually-supplied logo
═══════════════════════════════════════════════════════════════════════════

The Phase A icon downloader (`python scripts/download_org_icons.py`) auto-
fetched 66/76 org logos via Google's favicon service, direct /favicon.ico
fallback, and HTML-head <link rel="icon"> parsing. These 10 sites blocked
all three layers and currently show a colored first-letter circle in the
UI (the placeholder fallback in src/components/OrgIcon.jsx).

WORKFLOW
  1. Open the page, save the logo as the exact filename listed below.
  2. Drop it into  public/icons/<filename>.png  (overwriting the 67-byte
     placeholder that lives there now).
  3. Re-run:  python scripts/download_org_icons.py
     The script sees the new real PNG (>100 bytes), moves the org's name
     from MISSING_ICONS into ORG_ICON_MAP, and rewrites src/data/orgIcons.js.
  4. Commit + push — main auto-deploys to GH Pages.

You can do these one at a time. Filenames are stable across reruns.

 NOTES
───────────────────────────────────────────────────────────────────────────

* Required size: 64×64 px or larger; the UI scales them down to 12–14 px
  for chips and 14 px for region cards.
* Format: PNG with transparency preferred. JPG works too; SVG works if you
  rename the extension to .png (browsers sniff bytes — Vite serves the
  public/ folder raw without bundling).
* If you can't find a clean logo, the deterministic colored letter circle
  the UI shows now is a perfectly fine fallback — these orgs just won't
  stand out visually next to the ones that have real logos.

The auto-generated machine-readable version of this same list lives in
scripts/_org_icon_misses.md — same content in Markdown.
